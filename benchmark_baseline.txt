Naming Convention:
- "grids" = how the 3 rules are processed (seq = one at a time, par = all 3 in parallel)
- "cells" = how cells in each row are processed (seq, par, or SIMD)

Key Insight - Sync Overhead:
┌─────────────────────────┬────────────┬─────────┬─────────┐
│ Method                  │ Compute    │ Sync    │ Total   │
├─────────────────────────┼────────────┼─────────┼─────────┤
│ par grids / seq cells   │ 0.127s     │ 0s      │ 0.127s  │
│ par grids / SIMD cells  │ ~0.016s    │ ~0.171s │ 0.187s  │
│ par grids / SIMD (none) │ ~0.016s    │ 0s      │ 0.016s  │
└─────────────────────────┴────────────┴─────────┴─────────┘

Why "par grids / seq cells" (0.127s) beats "par grids / SIMD cells" (0.187s):
- SIMD uses flat UInt8 buffer for vectorization
- Must sync (copy) 200M values back to List[List[Int]] for compatibility
- Sync takes 0.171s (91% of total time!)
- Pure SIMD compute is 8x faster (0.016s vs 0.127s)

SIMD Implementation:
- Parallel bitmask lookup: (mask_vec >> codes) & 1 for 64 cells per instruction
- AVX-512: 512 bits / 8 bits = 64 cells processed simultaneously
- Throughput: 200M cells / 0.016s = 12.5 billion cells/second

CPU vs GPU Comparison:
- CPU SIMD (no sync): 0.016s - 11x faster than GPU!
- GPU (no CPU alloc): 0.178s
- The 9800X3D's 96MB L3 cache + AVX-512 beats GPU for this cache-friendly workload

Grid: 20,000 x 10,000 (200M cells) | 3 rules
Memory: RAM ~200 MB (down from 1.4 GB) | VRAM 762 MB

-----------------------------------------------

seq grids / par cells         0.353s       -

Native GPU                    0.757s    0.637s

-----------------------------------------------

Migration: List[List[Int]] → List[UInt8] (flat buffer)
- Eliminated sync overhead entirely (was 91% of SIMD time)
- Single data structure for all methods
- 8x memory reduction (Int → UInt8, no duplicate buffer)

Performance Improvements (vs SIMD with sync):

│ Method                  │ Before   │ After    │ Speedup │

│ seq grids / par cells   │ 1.273s   │ 0.353s   │ 3.6x    │
│ seq grids / SIMD cells  │ 0.924s   │ 0.136s   │ 6.8x    │

└─────────────────────────┴──────────┴──────────┴─────────┘

CPU SIMD vs GPU:
- CPU SIMD: 0.011s = 18.2 billion cells/second
- GPU (no alloc): 0.182s = 1.1 billion cells/second
- CPU is 17x faster than GPU for this workload!

Why CPU beats GPU:
1. 3D V-Cache (96MB L3) keeps entire working set in cache
2. AVX-512 processes 64 cells per instruction
3. Zero memory transfer overhead (GPU requires PCIe transfers)
4. Cache-friendly sequential access pattern
